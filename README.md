# 🚀 Python Space Shooting Game

**Python Space Shooting Game** is a 2D arcade-style space shooter developed using Python and Pygame. Take control of a spaceship, shoot incoming enemies, earn points, and progress through five challenging levels to save the galaxy!

## 🎮 Features

- **5 Challenging Levels** – Progress through five levels with increasing difficulty.
- **Player Movement** – Move your spaceship using keyboard controls.
- **Shooting Mechanism** – Shoot incoming enemies using projectiles.
- **Enemy Spawning System** – Enemies spawn randomly with varying sizes and speeds.
- **Score System** – Earn 10 points for every enemy defeated.
- **Collision Detection** – Detect collisions between the player, bullets, and enemies.
- **Sound Effects** – Procedurally generated shooting and hit sound effects.
- **Game States** – Includes Main Menu, Playing, Level Complete, Game Over, and Victory screens.

## 🎯 Controls

| Key | Action |
|---|---|
| `A` / `D` | Move left / right |
| `←` / `→` | Move left / right |
| `SPACE` | Shoot / Start game |
| `ENTER` | Start / Continue / Retry |
| `M` | Return to main menu |
| `ESC` | Quit game |

## 📦 Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/Raihananandaf/Python-Space-Shooting-game.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Python-Space-Shooting-game
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the game:

   ```bash
   python shooter.py
   ```

## 🎮 Objective

Defeat the required number of enemies in each level while avoiding enemy collisions. Each level becomes progressively more difficult as enemy speed increases.

Complete all five levels to save the galaxy!

## 📌 Project Purpose

This project was created as a Python programming practice project to explore game development concepts, object-oriented programming, game loops, collision detection, event handling, and procedural sound generation.
